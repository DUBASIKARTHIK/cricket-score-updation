# cricket-score-updation
# 🏏 Realtime Cricket Live Score Web Application

## 📌 Project Title

Realtime Cricket Live Score Web Application (CREX Style)

---

## 📖 Project Description

This project is a realtime cricket scoring web application where the admin updates match scores and users can view live scores instantly without refreshing the page.

---

## ❗ Problem Statement

Existing cricket score systems require manual refresh and do not provide instant updates.
This project solves the problem by implementing a realtime scoring system using modern web technologies.

---

## ✨ Features

* Live cricket score updates
* Ball-by-ball scoring system
* Admin panel for score management
* Automatic strike change logic
* Over calculation after 6 balls
* Realtime updates without page refresh
* Match creation and editing options

## ⚙️ Installation / Setup

1. Install Python (3.x)
2. Install Flask:
   pip install flask
3. Create Supabase project
4. Create required tables (matches, balls, scorecards)
5. Add Supabase credentials
6. Run the application:
   python app.py
7. Open browser:
   http://127.0.0.1:5000

---

## ▶️ Usage

* Admin creates a match
* Admin updates score using scoring buttons (0,1,2,4,6,W,NB,WD)
* System automatically updates runs, wickets, overs
* Users can view live scores instantly
