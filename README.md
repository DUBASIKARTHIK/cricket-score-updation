# 🏏 Cricket Score Updation (User Website)

## 📌 Project Description

This module displays live cricket scores to users in real-time.
Users can view match scores instantly without refreshing the page.

---

## ❗ Problem Statement

Users need a system where live cricket scores update instantly without manual refresh.

---

## ✨ Features

* Live match display
* Real-time score updates
* Match cards UI
* Ball-by-ball score view

---

## 🛠️ Technologies Used

* HTML

* JavaScript

* Supabase
